# Lexical Analyzer

## Project Overview

Lexical Analyzer is a C-based application that analyzes source code and identifies different types of tokens.

The analyzer processes the input source code and classifies elements such as keywords, identifiers, operators, constants, special symbols, and literals. It demonstrates the basic principles of lexical analysis used in compiler design.

## Features

- Identify C keywords
- Identify identifiers
- Identify operators
- Identify constants
- Identify special symbols
- Identify string and character literals
- Process source code character by character
- Classify tokens based on their type

## Compilation

Compile the project using GCC:

```bash
gcc *.c -o lexer
```

## Usage

Run the lexical analyzer using:

```bash
./lexer
```

The program processes the input source code and identifies and classifies the tokens present in it.

## Project Objective

The objective of this project is to implement a lexical analyzer in C and understand how source code can be processed and divided into meaningful tokens as part of the compilation process.
